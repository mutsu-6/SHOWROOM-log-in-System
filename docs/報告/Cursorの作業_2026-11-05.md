## 入室で訪問回数を増やす

`showroom_keeper/entrance.py` の入室。ブラウザのページは開かない。

今までの入室は `/api/live/current_user` (観客席にアバターが並ぶ) と `/api/room/greeting` (入室のお知らせ) だけだった。お知らせは出るが、訪問回数は増えないので、毎回「初訪問」になる。

配信ページ (2026-11-05 に取った公式のクライアント) は、ログインしていれば先に `/api/live/live_info` を呼び、そのあと greeting で「初訪問」か「N 度目の訪問」をお知らせする。入室も同じ順にした。

- ログインした Cookie のまま `/api/live/live_info?room_id=` を呼ぶ (訪問回数を増やす)
- 続けて `/api/live/current_user` (ステージのアバター)
- 続けて `/api/room/greeting` (お知らせ)。成功の判定は今までどおり greeting の `ok`
- `uuid` の Cookie は今までどおり、最初に配信ページを 1 回開いてもらい、6 時間使い回す
- 10 秒は待たない (待つとお知らせが出ないことがある。2026-10-18 に確かめてある)
- 映像の URL、アンケート、視聴の `polling`、ギフト、フォローは呼ばない
- live_info が失敗した時はお知らせを出さず、入室済みにしない (次の確認で入室し直す)

ログイン無しで公開の API を見た。有効な `sr_id` は次の問い合わせでも置き換わらない。greeting はログインが無いと 401 になる。ここから本番のアカウントでは確かめていないので、お知らせの文が「N 度目」に変わることは、サーバーに入ってから見る。
