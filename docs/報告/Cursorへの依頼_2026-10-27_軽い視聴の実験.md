# Cursor への依頼: ブラウザなしで観客席に居続けられるかの実験 (2026-10-27)

M さんが進めることを決めた (2026-10-27)。手順は Claude Code が決めた。
背景と、ほかの計画との関係は、プロジェクトの資料「今後の計画と別チャットの説明文_2026-10-27」の 2 節。

## 目的
今は、観客席 (ステージ) に自分のアバターを置くために、Playwright + Chrome で配信ページを開いている (1 ルーム 0.5〜1GB)。
ブラウザを開かずに、`/api/live/current_user` を 1 回呼び、`/api/live/polling` を 30 秒ごとに送り続けるだけで
観客席に居続けられるなら、1 ルームのメモリは数 MB になる。これが本当かを、一度の実験で確かめたい。

分かっていること (コード): `entrance.py` は current_user で観客席に並ぶ。`mission.py` は current_user + polling を 30 秒以上で
ミッションの「視聴」に数えられる (2026-10-22 にサーバーで確認)。**分かっていないこと**: 何時間いられるか・polling を止めると何分で消えるか・断られないか。

## やり方 (サーバーを重くしないため、Mac で動かす)
- アカウント: テスト用のアカウントがあればそれを使う。無ければ本番のアカウントでよい (入室は `entrance.py` が本番でもしている) が、
  **サーバーが視聴しているルームは選ばない** (本番のアバターに触れないため)
- ログイン状態: そのアカウントの `storage_state.json` (サーバーのものを写すか、Mac で `showroom-keeper login` で作る)。リポジトリには入れない
- ルーム: 配信が 4 時間ほど続きそうなルームを 1 つ (Classic の配信。観客席の上位 100 人に入れないほど混んだルームは避ける)
- 下のスクリプトを `/tmp/stay_check.py` などに保存し、リポジトリのフォルダで次のように動かす (3 時間 + 最大 1 時間)

```
python /tmp/stay_check.py <storage_state.json の場所> <ルームの room_url_key> | tee /tmp/stay_check.log
```

問い合わせは 30 秒に 1 回 (polling) と 10 分に 1 回 (観客席の一覧) ほど。今の収集 (0.5 秒に 1 回) よりずっと少ない。
**観客席を確かめる時に current_user は呼ばない** (呼ぶと入り直しになり、居続けたのかが分からなくなる。`watcher.py` の `_check_avatar` はこれを呼んでいるので使わない)。

```python
"""ブラウザなしで観客席に居続けられるかの実験 (読むだけ。ギフト・コメント・フォローはしない)。"""
import json, sys, time
from datetime import datetime
from showroom_keeper.entrance import Session

state_path, key = sys.argv[1], sys.argv[2]
cookies = json.load(open(state_path))["cookies"]
s = Session(cookies)
POLL, CHECK, KEEP, AFTER, AFTER_CHECK = 30, 600, 3 * 3600, 3600, 120

def get(path):
    return json.loads(s.get(path))

def out(*a):
    print(datetime.now().strftime("%H:%M:%S"), *a, flush=True)

st = get(f"/api/room/status?room_url_key={key}")
room_id, live_id = st["room_id"], st.get("live_id")
if not st.get("is_live"):
    sys.exit("配信していません")
me = get(f"/api/live/current_user?room_id={room_id}")
uid = me.get("user_id")
out("入室", "ログイン", me.get("is_login"), "live_id", live_id)
if not me.get("is_login") or not uid:
    sys.exit("ログインしていません")

def seat():
    """(観客席にいるか, 順位, 観客席の人数, 配信中か)。current_user は呼ばない。"""
    now = get(f"/api/room/status?room_url_key={key}")
    live = bool(now.get("is_live")) and now.get("live_id") == live_id
    lst = get(f"/api/live/stage_user_list?room_id={room_id}").get("stage_user_list") or []
    hit = next((x for x in lst if str((x.get("user") or {}).get("user_id")) == str(uid)), None)
    return bool(hit), (hit or {}).get("rank") or (hit or {}).get("order_no"), len(lst), live

start = time.time()
last_check = -CHECK
errors = 0
while time.time() - start < KEEP:  # 1. polling を送り続ける
    try:
        s.get(f"/api/live/polling?room_id={room_id}")
    except Exception as e:  # noqa: BLE001
        errors += 1
        out("polling の失敗", type(e).__name__, str(e)[:80])
    if time.time() - last_check >= CHECK:
        last_check = time.time()
        on, rank, n, live = seat()
        out(f"送り続けて {int((time.time() - start) / 60)} 分", "観客席に", on, "順位", rank, "人数", n, "配信中", live)
        if not live:
            sys.exit("配信が終わったので終わり (ここまでの結果を報告してください)")
    time.sleep(POLL)

out("polling を止めます (失敗", errors, "回)")  # 2. 止めて、何分で消えるか
stop = time.time()
while time.time() - stop < AFTER:
    time.sleep(AFTER_CHECK)
    on, rank, n, live = seat()
    out(f"止めて {int((time.time() - stop) / 60)} 分", "観客席に", on, "順位", rank, "人数", n, "配信中", live)
    if not on or not live:
        break
```
