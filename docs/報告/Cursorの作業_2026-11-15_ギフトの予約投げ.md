| 種類 | 送り先 | 画面の定数 |
| --- | --- | --- |
| 無料 (1 回) | `POST /api/live/gifting_free` | `API_POST_LIVE_GIFTING_FREE` |
| 有料 | `POST /api/live/gifting_point_use` | `API_POST_LIVE_GIFTING_POINT` |
| 無料をまとめて | `POST /api/live/bulk_gifting_free` | `API_POST_LIVE_BULK_GIFTING` |

1 個の星は、上の無料 (1 回) を使う。まとめて送る方は、星 1 個の予約では使わない。

送る項目 (画面が作る JSON を、`application/x-www-form-urlencoded` に直して送る):

- `gift_id`
- `live_id`
- `num`
- `is_delay` (画面は `0`)
- `csrf_token` (POST の直前に、`GET /api/csrf_token` の値を末尾へ足す)
- `route` (画面が渡した時だけ)

`showroom_keeper/entrance.py` の `post_with` は、同じ項目を同じ Content-Type で送る。

### 返事の形

成功の JSON に `ok` は無い。画面が読んでいる項目は次のとおり。

無料:

- `fan_level.fan_level`
- `notify_level_up`
- `mission.has_achievement` (ある時)
- `h`
- `n` (0 以下の時、画面は演出を出さない。HTTP は 200 のまま)
- `ua`
- `class_level`
- `class_level_image`

有料は、それに加えて `remaining_point`・`remaining_expiring_point`・`active_fan.before_level`・`active_fan.current_level`・`active_fan.title_id`。

今の判定は、HTTP 200 で `error`・`errors`・`ok: false` が無ければ「送った」になる。`n` が 0 でも「送った」になる。
