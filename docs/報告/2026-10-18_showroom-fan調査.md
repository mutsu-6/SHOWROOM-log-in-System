# showroom-fan.com (非公式ファンサイト) の調べ (2026-10-18)

個人が運営する非公式のサイト。配信者・リスナー向けに、SHOWROOM の公開の情報を集めて見せている。
ここで分かったことと、このシステムに取り入れたいことのまとめ (名前・ID は書かない)。

## このサイトでできること
| 機能 | 中身 | 情報のもと (推測をふくむ) |
| --- | --- | --- |
| 配信者ダッシュボード | フォロワー数・SHOWランク (例: B-5)・まいにち配信の日数・最終アクセス・月末ごとのフォロワーの増減 | `/api/room/profile` (show_rank_subdivided・live_continuous_days など) |
| 月間ファン数・ファンパワーの推移 | 公式では見られない先月より前の月も出る。リスナー別の月ごとのファン情報 (ファンパワー・累計・回数・最高レベル) | `/api/active_fan/*`。**公式の API でも ym を指定すれば 2022-02 ごろから前の月を読める** (2026-10-18 に確かめた。サイトの数字と同じ) |
| 配信履歴 | 配信ごとの時間・**最大の盛り上がり度**・フォロワーの増減 (例: 1,166 → 1,148)。約 5 分ごとに更新 | 配信中に約 2 分ごとに確かめている |
| 配信の詳細 | 盛り上がり度の推移・**来場・ファンレベルが上がった・フォローの記録**・歌った曲・**配信ごとの貢献ランキング (上位 100 人)** | リアルタイム通信のシステムの知らせ、`/api/live/summary_ranking` など |
| 配信ログ | コメント・ギフト (スペシャル・無料別)・システムの知らせを、配信中も配信後も見られる | 見ている人のブラウザでリアルタイム通信 (`wss://online.showroom-live.com`) を受けて、サイトに送る |
| カラオケランキング | 配信者が歌った曲を数える (日・週・月)。曲・歌手で探せる。2026-01-20 から | カラオケのテロップ (`/api/live/telop`) |
| ギフト一覧 | 全ギフトをカテゴリ別に (無料・有料・タワー・グリッター・季節など) | `/api/live/gift_list` |
| フォロワー増加数ランキング | 月ごとの上位 100 ルーム (2026-05 から) | 毎月のフォロワー数 |
| Chrome 拡張 | キーボードでギフトの 10 連投・全画面。ログを 50 件から 200 件に増やし、時刻・ポイント・**2.5 倍の対象か**を出す | — |

## このシステムに無いもの・取り入れたいもの
1. **ルームのプロフィール (`/api/room/profile`) を読んでいない** (確かめた)。読めば次が分かる
   - SHOWランク (show_rank_subdivided・前の月の prev_show_rank_subdivided)、リーグ (league_id・次の月の next_league_id。
     イベントの league_ids と同じ番号)、SHOWグレード、まいにち配信の日数 (live_continuous_days)、前の週のスコア (prev_score)、
     配信スタイル (broadcast_style。Classic か Salon)、個人かグループか (room_group_config_type)、公式か (is_official)
   - イベントの「出られるリーグ」と、ルームのリーグを突き合わせられる (出るイベントの選び方に効く)
2. **配信ごとの貢献ランキング** (`/api/live/summary_ranking`。今の配信の上位): イベントの外の、ふだんの配信でだれが支えているか
3. **リアルタイム通信のシステムの知らせ** (来場・フォロー・ファンレベルが上がった): 記録しているルームで数えれば、
   誘い投げのあとに来場・フォローが増えたかも見られる (今はギフトとコメントの数だけ)
4. **盛り上がり度** (ルームの左上の数字): 配信中の勢い。どの API で取れるかは、まだ確かめていない
5. **月ごとのアクティブファン**: 公式の API で前の月も読めると分かったので、最近配信したルームから、新しい月へさかのぼって読み足す (`sweep._next_fans_history`)

## このサイトでしか取れないもの
- 過去の配信ごとの記録 (フォロワーの増減・盛り上がり度・来場とフォロー)。公式は配信中にしか見られないので、こちらは今から集めるしかない。
  利用者の判断 (2026-10-18): このサイトからしか取れないものが無いなら、公式から取る → 公式から取れるものは公式から取り、このサイトからは取らない
6. カラオケ (歌った曲): 分析の目的 (ギフター・イベント) には遠いので、後回し
