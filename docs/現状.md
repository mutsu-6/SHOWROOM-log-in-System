## 今の設定と動き
- 視聴しているルーム: 3 つ (テスト用のサンプル。本番のルームではない)
- 応援しているルーム: 設定していない (分析は「応援ルームなし」の表示で使っている)
- 全ルームの収集: `.env` に `SHOWROOM_RESEARCH_ALL=true` を入れ、2026-10-16 06:28 (UTC) に開始
  - ログ: 「SHOWROOM の全ルームの情報を集め始めます (ルーム番号の調べ: する)」「配信中のルームから 127 ルームを新しく見つけました」。エラーなし
  - 貢献ランキングは 2015 年ごろのイベントから取れる (以前は 9 か月より前は取れないと考えていたが、誤りだった)。イベントの参加ルームと順位は 2014 年から取れる
  - 古いイベントまで全部集め終わるまで約 2 か月。問い合わせは 1 秒に 1 回のままなので、SHOWROOM への負荷の強さは変わらない
  - `research.db` は数 GB になる見込み (ディスクの空きは 15GB)
  - ユーザー ID から推測する登録時期は「遅くともこの月まで」。集めた情報が少ないうちは実際より新しく出て、いちばん古い年には、それより前に登録した人もまとめて入る
- 開催中のイベントのポイントの推移: 全ルームの収集の中で、開催中のイベントの参加ルームのポイントと順位を 1 時間に 1 回 `event_progress` に残す (2026-10-17 から)。イベントが終わったあとも消さない。終わったあと参加ルームを読み直した時 (終わって 1 日ほど) に、最終結果を「終わった時刻の値」として推移の最後に入れる。画面と勝者予想はまだ作っていない (推移を貯めてから)
- 気になるギフター (ウォッチリスト): 「分析」のギフターの詳しい表示の「☆ 気になる」で印を付け、メモ (500 字まで) を残せる。印を付けた人は「分析」の上に「気になるギフター」として並ぶ。`research.db` の `watch` 表に保存 (SHOWROOM への問い合わせは増えない)
- 離れつつある人・伸びている人: 「分析」の上に出す。イベントの貢献ポイントを、最近の期間とその前の期間 (12・6・3 か月のうち、比べられるいちばん長いもの) で比べる。**集め終わった月どうしでだけ比べる** (全ルームの収集は新しいイベントから取るので、集め終わっていない古い月と比べると、だれでも「最近増えた」ように見えるため)。集め終わった月 = その月に終わったイベントの貢献ランキングを 95% 以上取り、過去のイベントの読み込みがその月より前まで進み、見つけたルームの 95% 以上を集め終えたもの (ルーム番号の調べで見つけた、フォロワー 0 人で配信の記録も無いルームは、取らないので数えない)。今は全ルームの収集の途中なので「まだ比べられません」と出る
- 問い合わせを止める時間: 5 回続けて失敗したら止める。1 時間・2 時間・4 時間… と続けて止めるたびに倍 (最大 24 時間)。再開後 200 回続けて成功したら 1 時間に戻す。止めている時・24 時間以内に止めた時はダッシュボードの上に出る。keeper を起動し直すと、止めた回数は 0 に戻る
- 月ごとの集計 `user_month` (ギフター × 月のイベントの貢献ポイント): 貢献ランキングを保存するたびに足し引きする (取り直した時は前の分を引く)。前に集めた分は、全ルームの収集の合間と分析の時に少しずつ入れる。年ごとの集まり具合は「離れつつある人・伸びている人」の下に出す
- ギフターの詳しい表示の「支出の移り変わり」の「最近 12 か月とその前の 12 か月」: 集め終わっていない月を含む時は、当てにならないことを注意書きで出す (累計ランキングの増えは、集め始める前の月が 0 になることも)
- ギフトの一覧: 起動時と毎週月曜日 0:00・3:00・12:00・15:00・18:00 (日本時間) に取り直す
- 配信ページは空白のページの裏 (背面のタブ) に開き、画質は中画質 (640x360) で CPU を抑えている

## バックアップ
- `research.db` は毎日 4:00 (日本時間) に、SQLite のバックアップの仕組みで `data/backup/research-YYYYMMDD-HHMM.db` に写す (新しい 2 つを残す)。
  書き込み中の research.db をそのままコピーすると壊れた写しになることがあるので、手でコピーしない
- 写しを作るのにディスクの空きが足りない時はやめて、管理画面「分析」タブの上の欄に出す
- 写しはサーバーの中だけにある。サーバーが壊れた時に備えるには、Google Cloud Storage などに移す (未設定)
